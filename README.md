# MaisonFit

Ton look du jour choisi parmi tes propres vêtements, selon la météo et ton programme.

## Lancer l'appli sur ton ordinateur

```
npm install
npm run dev
```

## Contrôles automatiques

À chaque envoi sur GitHub, le CI (dossier `.github/workflows`) installe, teste, construit l'appli puis l'ouvre dans un vrai navigateur en taille téléphone et ordinateur. Les captures d'écran sont téléchargeables dans l'onglet Actions.
